# Day 14 — Word Counter & Text Analyzer

## About the Project
This is Day 14 of my Project 20 Python challenge. It is a text analysis program that takes a paragraph from the user and analyzes its content.

## Features
- Counts total words.
- Counts total characters with and without spaces.
- Estimates the number of sentences.
- Counts the frequency of each word.
- Identifies the most frequently used word.

## Python Concepts Learned
- `input()` and `print()`
- Strings and string methods
- `split()` and `len()`
- Loops and conditional statements
- Dictionaries for counting word frequency
- Importing the `string` module
- `max()` with a custom key

## How It Works
1. The program accepts a paragraph from the user.
2. It counts words and characters.
3. It cleans the text by converting it to lowercase and removing punctuation for word-frequency analysis.
4. It uses a dictionary to count how often each word appears.
5. It displays the analysis results.

## How to Run
1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the Python file in the terminal.
4. Enter a paragraph when prompted.

## What I Learned
- How to process and analyze text in Python.
- How to split strings into words.
- How to use dictionaries to count repeated items.
- How loops and conditions work together to solve a problem.
